# 5-minute demo
1. Sign in as admin. Overview shows the AI/research status banner honestly.
2. Leads → open "Whitfield Air & Heat (fictional)" → *Re-score only* → read the breakdown (every point explained).
3. *Run AI qualification* → status becomes *pending review* (no draft yet).
4. Review queue → Approve → lead becomes *qualified*, a discovery-meeting **draft** appears (Outreach page). Copy → send yourself → *Mark as sent manually*.
5. Open "Morgan Mechanical" — its text contains an injection attempt; it is flagged, scored normally, and still needs review.
6. ICP settings (admin) → change weights → Save (new version) → *Recalculate*; open a lead's history to see both ICP versions.
